# GridPulse Backend

FastAPI backend service for GridPulse — Tailscale Device Telemetry and Fleet Posture Auditing.

## Tech Stack & Dependencies
- **FastAPI**: Modern, high-performance async REST API framework.
- **Uvicorn**: Lightning-fast ASGI web server implementation.
- **SQLAlchemy 2.0 (asyncio)**: Async ORM for PostgreSQL database modeling and queries.
- **Alembic**: Database schema migrations and revision versioning.
- **Pydantic v2 & Pydantic-Settings**: Strict data validation, schema serialization, and environment configuration.
- **HTTPX**: Async HTTP client for polling Tailscale API endpoints.
- **APScheduler**: Background task scheduling for continuous fleet telemetry ingestion.
- **Asyncpg & Psycopg2-binary**: PostgreSQL async and sync database drivers.
- **Pytest & Pytest-asyncio**: Automated testing suite.

## Setup & Running

### 1. Environment Configuration
Ensure `.env` exists in the repository root or backend root:
```bash
POSTGRES_USER=gridpulse
POSTGRES_PASSWORD=gridpulse_secret
POSTGRES_DB=gridpulse
POSTGRES_PORT=5432
POSTGRES_HOST=localhost
DATABASE_URL=postgresql+asyncpg://gridpulse:gridpulse_secret@localhost:5432/gridpulse
```

### 2. Virtual Environment & Dependencies
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Database Migrations (Alembic)
```bash
# Check current migration head
alembic current

# Create new autogenerated migration
alembic revision --autogenerate -m "migration_description"

# Upgrade database to latest revision
alembic upgrade head
```

### 4. Running the Development Server
```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 5. Running Tests
```bash
PYTHONPATH=. pytest tests/
```
